# Campus Navigation and Resource Management

`IntegratedTaskCode.py` is a Python demonstration of common data
structures and algorithms in a campus navigation scenario.

It includes:
- A weighted, undirected campus graph with DFS, BFS, and Dijkstra's shortest path.
- A bounded stack for recent building history and a FIFO shuttle queue.
- A binary search tree and a linear-probing hash table for room lookups.
- A heap that reports the three busiest locations.

## Run

Requires Python 3; no third-party packages are needed.

```bash
python IntegratedTaskCode.py
```

The script prints sample routes, room lookups, busiest locations, navigation
history, and the next shuttle. Edit the sample data in `main()` to explore
different buildings, paths, rooms, or footfall counts.
